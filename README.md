# Abrielle's Digital Canvas

Build me a sleek, modern one-page portfolio website for a Social Media Coordinator / Content Marketing position at a major consulting firm in New York City.

The portfolio belongs to **Abrielle Jasmin**.

The goal is to create something that feels polished enough for a corporate consulting firm while still showing creativity, visual taste, digital fluency, and an understanding of social media. It should NOT feel like a generic student portfolio, Canva template, influencer website, or overly artistic design portfolio.

### Overall Creative Direction

Style:
- Minimal
- Editorial
- Modern
- Sophisticated
- Creative but professional
- Clean typography
- Lots of intentional whitespace
- Subtle motion and interaction
- Premium agency / consulting / creative-strategy feel

Think:
**New York creative agency meets modern consulting firm.**

Use a mostly neutral palette:
- Off-white / cream background
- Black or charcoal typography
- Soft gray details
- One subtle accent color if needed

Avoid:
- Bright gradients
- Excessive rounded cards
- Glassmorphism
- Overly playful illustrations
- Huge blocks of text
- Generic stock photos
- Excessive animations
- Anything that screams “AI-generated website”

The site should feel intentionally art-directed.

## 1. HERO SECTION

Keep the hero clean and strong.

Display:

**Abrielle Jasmin**

Large headline:

**Social Media • Content • Digital Storytelling**

Supporting line:

“I create thoughtful digital content that turns ideas into clear, engaging visual stories.”

Include a small CTA:
**View Selected Work ↓**

Optional smaller descriptor:

Computer Science + Economics | Spelman College

Do NOT overcrowd the hero.

Add a subtle creative visual element such as typography, thin grid lines, image cropping, or editorial layout instead of a generic hero illustration.

---

## 2. SELECTED WORK

This should be the main focus of the website.

Create an editorial portfolio grid where I can upload images of my work.

Each project should have:
- Large project image
- Project name
- Category
- One short description
- Optional “View Project” interaction

Allow projects to have multiple images.

Design the portfolio so that projects can easily be added, removed, or reordered later.

Initial example categories may include:

**Social Content**
Instagram graphics, branded posts, promotional assets, announcements, educational content, event marketing.

**Campaign Concepts**
Content ideas or campaign concepts demonstrating how I would translate a message across digital platforms.

**Visual Storytelling**
Graphics, presentations, posters, branded visuals, or digital experiences.

**Innovation / Technology**
Creative work involving AI, emerging technology, research communication, or digital projects.

Do not fabricate campaign results, engagement statistics, clients, or professional experience.

---

## 3. FEATURED PROJECT CASE STUDY

Create one larger featured-project section that allows me to explain the thinking behind a project.

Use this structure:

PROJECT NAME

**Challenge**
What needed to be communicated?

**Approach**
How did I translate the idea into content?

**Creative Direction**
What visual, messaging, or branding decisions did I make?

**Deliverables**
Examples such as:
- Social graphics
- Campaign concept
- Poster
- Promotional content
- Digital storytelling
- Presentation design

Keep each section brief.

The layout should prioritize imagery over text.

---

## 4. HOW I THINK ABOUT SOCIAL

Add a short section showing that I understand social media as more than graphic design.

Headline:

**Content with a reason behind it.**

Include 4 simple principles displayed in a clean editorial layout:

**Clarity**
Make the message understandable immediately.

**Consistency**
Create visuals and messaging that feel like one recognizable brand.

**Audience**
Understand who the content is speaking to before deciding how it should look.

**Adaptability**
Translate one idea across different channels, formats, and audiences.

Keep this section visually minimal.

## 6. ABOUT

Keep this brief.

Use:

“I’m Abrielle Jasmin, a Computer Science major and Economics minor at Spelman College with experience across technology, research, innovation, and creative communication.

I’m especially interested in the way brands translate complex ideas into digital experiences that people actually want to engage with. My background allows me to approach content from both a creative and analytical perspective — thinking about the message, the audience, and the system behind it.”

Include space for a professional photo, but allow the section to work without one.

---

## 7. CONTACT

Simple final section.

Headline:

**Let’s create something worth paying attention to.**

Include:
- Email
- LinkedIn
- Resume button

Use placeholders where my actual contact links need to be inserted.

---

## DESIGN DETAILS

Use sophisticated typography with a strong sans-serif font.

Typography should be one of the strongest visual elements of the site.

Use:
- Large editorial headings
- Small uppercase category labels
- Clear hierarchy
- Strong image cropping
- Subtle hover effects
- Smooth scrolling
- Gentle reveal animations

Avoid making every section a floating rounded rectangle.

Instead, use:
- whitespace
- thin dividers
- columns
- grids
- typography
- asymmetrical layouts where appropriate

For project cards, allow images to expand into a larger lightbox or project view.

Make the website fully responsive for desktop, tablet, and mobile.

Desktop should feel especially polished because recruiters and hiring managers may view the portfolio from a computer.

Add a small sticky navigation with:

Work  
About  
Capabilities  
Contact

Do not create unnecessary pages or complicated navigation.

---

## IMPORTANT

This portfolio is being created before I receive the exact Social Media Coordinator job description, so make the structure FLEXIBLE.

I should be able to:
- Add new portfolio pieces easily
- Rearrange projects
- Change categories
- Replace copy
- Add campaign case studies later
- Add social media metrics later if I obtain legitimate metrics
- Tailor the portfolio toward a specific employer without redesigning the entire website

Prioritize visual polish, simplicity, credibility, and strong presentation over adding lots of features.

The finished website should make a recruiter think:

**“She understands presentation, branding, communication, and digital culture.”**
